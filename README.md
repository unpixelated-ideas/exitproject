# The Exit Project

An independent civic prototype for proposing NYC subway exit numbers.

**Website:** https://unpixelated-ideas.github.io/exitproject/

The React + TypeScript application is in [`application/`](application/). See its [README](application/README.md) for setup and architecture.

This is a frontend demonstration. Ballots remain in browser storage; submissions are simulated and no real votes are collected. Not affiliated with or endorsed by the Metropolitan Transportation Authority.

## Publishing

GitHub Actions checks and builds the application, then publishes it to GitHub Pages whenever changes are pushed to `main`. In the repository's Settings → Pages, the source should be **GitHub Actions**.

The original reference workbook stays in the local project and is not included in this repository.
